• Bruker DataLoader

    Direct import of processed 1D Bruker NMR datasets (ImportBrukerSpectrum, PlotBrukerSpectrum, ToSignal) with acquisition/processing metadata access and seamless conversion into SpinDynamica time-domain signals.

  • Optimal Control (GRAPE & Time-Optimal Control)

    Analytical-gradient GRAPE optimization (OptimalControlProblem, GRAPEOptimize), robust ensemble pulse design, constrained and second-order optimizers, time-optimal control, and independent verification against NPropagationOperator.

  • Signal2D & Performance Improvements

    High-performance 2D NMR simulation (Signal2D) featuring Hilbert/Liouville blocked double-diagonalization, compiled kernels, hypercomplex and TPPI quadrature, periodic MAS COMPUTE2D, and 2D processing and contour plotting (FT, PlotSpectrum2D).

  • Wolfram Paclet Distribution

    Packaged as a standard Wolfram Paclet (.paclet) for one-line installation via PacletInstall alongside traditional $Path setup.
